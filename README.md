# RNA Resources Educational Materials

A curated collection of educational resources for learning about RNA bioinformatics, RNAcentral, and Rfam. These materials are suitable for teaching at the upper undergraduate and graduate level.

## About

This repository aggregates training materials, tutorials, and educational resources related to:
- [RNAcentral](rnacentral.org) database and tools
- [Rfam](rfam.org) database and covariance models


## Target Audience

- Upper undergraduate students in bioinformatics, computational biology, or molecular biology
- Graduate students and researchers new to RNA bioinformatics
- Educators developing courses on RNA and genomics
- Bioinformaticians seeking training resources

### Videos

### Assignments & Exercises
Practical exercises and problem sets

### Background Materials

## Contributing

We welcome contributions! If you have educational materials related to RNAcentral or Rfam that you'd like to share:

1. Check our [Submit a new educational resource template](new_resource.md)
2. Submit materials via [GitHub Issues](../../issues) or Pull Request
3. Include metadata: title, description, level, format, topics covered

All contributed materials should be:
- Publicly accessible (or have permission to share)
- Relevant to RNAcentral or Rfam
- Suitable for educational purposes
- Properly attributed to original authors
